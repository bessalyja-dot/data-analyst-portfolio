## Кейс 1: продажи онлайн-ритейлера

Данные — [UCI Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii):
реальные заказы британского онлайн-магазина подарков, декабрь 2009 — декабрь 2011,
1 067 371 строка.

```bash
python3 case-retail/prepare.py    # скачивание, очистка, SQLite
python3 case-retail/analysis.py   # SQL + pandas → output/findings.json
```

Нужны `pandas` и `openpyxl`. Исходный файл (46 МБ) и база в репозиторий не кладутся —
`prepare.py` скачивает их сам.

| Файл | Что делает |
|---|---|
| `case-retail/prepare.py` | все правила очистки; печатает, сколько строк убрано и почему |
| `case-retail/queries.sql` | выручка по месяцам, ABC с оконной функцией, RFM, когорты, возвраты |
| `case-retail/analysis.py` | RFM-сегменты, матрица когорт, витрина для страницы |

## Кейс 3: инвентаризация бара

Реальная сличительная ведомость заведения, используется с разрешения. Исходный файл
в репозиторий **не попадает** (`*.xlsx` в `.gitignore`) — скрипт принимает путь к нему
аргументом и отдаёт наружу только доли и проценты.

```bash
python3 case-bar/prepare.py "путь/к/ведомости.xlsx"
```

Обезличивание: название организации не сохраняется, все суммы пересчитаны в проценты
от стоимости учётного остатка, пометки кладовщика сведены к типам причин.

## Как устроены графики

`assets/charts.js` — линия с курсором, горизонтальные бары и тепловая карта на голом SVG,
без библиотек. Цвета берутся из CSS-переменных, поэтому тёмная тема работает без
перерисовки. Палитра проверена на различимость при дальтонизме.
